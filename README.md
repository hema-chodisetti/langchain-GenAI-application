# LangChain GenAI Application

A simple Generative AI application built as part of my learning journey.

## Technologies Used

- LangChain
- Ollama
- Streamlit
- LangSmith
- Python

## Features

- Simple question-answer interface
- Local LLM integration using Ollama
- Prompt templates using LangChain
- Output parsing
- LangSmith tracing and monitoring

## Run Locally

```bash
pip install -r requirements.txt
streamlit run "1.2-ollama/app.py"
